# Guide

This guide. It is bundled with the app and works offline.

## Using it

- Pick a page on the left. Pages **00–04** cover the app as a whole: overview, hardware, workflow, checksum families and safety.
- Pages from **10** up each cover one panel, in roughly the order they appear in the sidebar.
- Each panel page follows the same layout: what you need, step by step, reading the results, common errors, and safety.

## If the guide is empty

The sidebar footer shows `guide: ✓` when the guide files were found. If it
shows `✗`, the build is missing its guide resources. Reinstall, or read the
same Markdown files in the project source under `desktop/src-tauri/guide/`.
