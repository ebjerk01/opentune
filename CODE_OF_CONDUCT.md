# Code of conduct

OpenTune follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions
about the project. Harassment, personal attacks and publishing other people's
private information are not accepted.

Project-specific expectations:

- Don't post or request material that isn't yours to share: OEM security-access
  algorithms, protected calibration data, or content from commercial tools.
- Don't post vehicle identifiers (VINs, registration plates) or other people's
  ECU images.
- Requests for immobiliser removal, odometer changes or emissions-control defeat
  are out of scope and will be closed.

Report problems privately to the maintainer through GitHub
([@ebjerk01](https://github.com/ebjerk01)) or a private security advisory on this
repository. Reports are handled confidentially; the maintainer may warn, remove
content from, or ban anyone who breaks this code of conduct.
